# 💤 LazyVim

- What this is — LazyVim config, no extras.
- Features — session durability (the four custom mechanisms, as detailed earlier), beancount support (hxueh/beancount.nvim, blink.cmp source, treesitter parser, needs python3), LazyVim's standard set (LSP/mason, conform, blink.cmp, gitsigns, noice, snacks, which-key, tokyonight/catppuccin), StyLua at 2-space/120-col, neoconf lua_ls.
- Install — git clone https://github.com/dbrugan/dbrugan-lazyvim.git ~/.config/nvim then launch nvim to bootstrap; symlink alternative for a checkout kept elsewhere; note that ~/.local/share/nvim persists across reinstalls.
